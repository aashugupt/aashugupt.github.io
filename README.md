# Bada Bhaktmaal Ashram Website

Official GitHub Pages website for Bada Bhaktmaal Ashram, Ayodhya - A sacred spiritual institution dedicated to Shri Ram Bhakti, Seva, and Sanatan Dharma.

## Website Structure

- **index.html** - Homepage with about, activities, history timeline, and CTA
- **services.html** - Religious & spiritual services, Annadan, humanitarian activities
- **vision.html** - Mission, vision, and core values
- **history.html** - Detailed history timeline from establishment to present
- **gaushala.html** - Information about cow protection and Gaushala Seva
- **accommodation.html** - Devotee accommodation booking information
- **guruji.html** - About Mahanth Swami Shri Avdheshkumar Das Ji Maharaj

## Features

- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Clean, modern spiritual theme
- ✅ Easy navigation with dropdown menus
- ✅ Contact information prominently displayed
- ✅ Social media integration
- ✅ Smooth scrolling and transitions
- ✅ GitHub Pages compatible

## Technologies Used

- HTML5
- CSS3 (Custom styling with CSS Grid and Flexbox)
- Vanilla JavaScript (no dependencies)

## Setup for GitHub Pages

1. Repository is already configured at `https://github.com/aashugupt/aashugupt.github.io`
2. Website will be automatically published at `https://aashugupt.github.io`
3. Any push to the main branch will update the live site

## Local Development

To view the website locally:
1. Clone the repository
2. Open `index.html` in your browser
3. No build process required
